3과목이 연결된 하나의 흐름입니다

이 시험이 묻는 것
기업은 왜 데이터를 시각화하는가?
더 나은 의사결정을 위해서입니다. 그 과정이 곧 3과목의 흐름입니다.
1과목어떤 정보가 있는가
→
2과목어떻게 다루는가
→
3과목어떻게 보여주는가
1과목
경영정보 일반
기업 활동에서 어떤 정보가 만들어지는가
회계·재무 → 돈의 흐름
인적자원 → 사람의 흐름
마케팅·영업 → 고객의 흐름
공급관리 → 물건의 흐름
외부정보 → 공공 데이터 포털
경영정보 활용 → SWOT, BCG 등
핵심: 용어와 개념의 층위 구분
2과목
데이터 해석 및 활용
그 데이터를 어떻게 이해하고 다루는가
데이터 이해 → 종류·통계·확률
파일·DB → 저장 구조, SQL
데이터 가공 → 정제·변환·결합
데이터 관리 → ETL·백업·보안
BI 활용 → 의사결정 연결
핵심: 데이터 처리 과정의 순서
3과목
경영정보시각화 디자인
데이터를 어떻게 시각적으로 전달하는가
디자인 원리 → 게슈탈트·색·원칙
차트 선택 → 목적별 적합 차트
도구 활용 → 엑셀, Power BI, Tableau
대시보드 → 여러 차트 통합 구성
핵심: 차트 이름과 특징 연결
3과목 비교
구분 1과목 2과목 3과목
질문 어떤 정보가 있는가? 어떻게 다루는가? 어떻게 보여주는가?
핵심 경영 용어와 개념 데이터 처리 과정 차트 선택과 디자인
주의할 점 용어 범위가 넓음 DB·통계·처리 흐름이 섞임 차트명·용도 구분이 중요함
