① 데이터 종류·특성
개념시험용 한 줄 구분헷갈리는 포인트
정형 vs 반정형 vs 비정형 정형=구조 고정(엑셀·DB) / 반정형=구조+설명(XML·JSON) / 비정형=구조 없음(이미지·SNS) JSON·XML은 정형 아님
범주형 vs 수치형 범주형=사칙연산 의미 약함 / 수치형=크기·차이 계산 가능 학년·등급은 범주형(순서형)
확증 편향 vs 체리피킹 확증편향=기존 믿음에 맞는 정보만 받아들임 / 체리피킹=유리한 데이터만 골라 제시 둘 다 편향이지만 방향이 다름
지수분포 vs 푸아송분포 지수분포=사건 사이 경과시간 / 푸아송분포=단위시간 내 발생 횟수 대기시간=지수, 발생횟수=푸아송
카이제곱검정 범주형 데이터 간 독립성 검정 수치형 데이터 검정 아님
② 파일시스템·DB
개념시험용 한 줄 구분헷갈리는 포인트
파일시스템 vs DBMS 파일시스템=단순저장(중복·검색 약함) / DBMS=중복최소화·무결성·보안 DBMS는 파일시스템 단점을 극복하기 위해 등장
RDBMS vs NoSQL RDBMS=테이블·SQL·정형 / NoSQL=동적스키마·비정형·반정형 계층형 구조 저장은 RDBMS 특징 아님
슈퍼키 vs 후보키 슈퍼키=유일성만 / 후보키=유일성+최소성 최소성 여부가 핵심 구분
기본키 vs 외래키 기본키=NULL불가·중복불가 / 외래키=다른 테이블 기본키 참조 외래키는 중복 가능
스키마 3단계 외부(사용자뷰) → 개념(전체논리구조) → 내부(물리저장) 외부=사용자 관점 / 개념=전체 논리 구조 / 내부=물리 저장 구조
DDL vs DML DDL=구조 정의(CREATE·ALTER·DROP) / DML=데이터 조작(SELECT·INSERT·UPDATE·DELETE) ALTER=구조변경 / UPDATE=데이터변경 혼동 주의
③ 데이터 가공·관리
개념시험용 한 줄 구분헷갈리는 포인트
ETL 3단계 추출(원천에서 가져옴) → 변환(정제·형식통일) → 적재(목표저장소) 추출 단계에서 변환하지 않음
백업 3종 전체=모두백업(복원빠름) / 증분=직전이후변경분(복원느림) / 차등=전체이후변경분전부 증분 백업은 복원이 느림
결측값 처리 삭제 / 평균·중앙값 대체 / 회귀 대입 로그 변환은 결측 대체 아님
이상값 기준 Q1−1.5×IQR 미만 또는 Q3+1.5×IQR 초과 IQR 전체 범위 밖이 아님
비식별화 구분 가명화=식별자 대체 / 익명화=식별불가 / 임의화=잡음추가 / k-익명성=동일레코드 k개이상 임의화는 잡음 추가 방식
정규화 vs 표준화 정규화=0~1범위 / 표준화=평균0·표준편차1(Z-Score) 이름이 비슷하지만 결과 범위 다름
④ BI·데이터 웨어하우스
개념시험용 한 줄 구분헷갈리는 포인트
데이터 웨어하우스 특성 주제중심·통합·시간포함·비휘발성 실시간 처리 최적화 아님
OLAP vs OLTP OLAP=다차원분석(의사결정) / OLTP=트랜잭션처리(업무·실시간) OLAP은 분석용, OLTP는 운영용
Dimension vs Fact Dimension=설명속성·범주형(날짜·지역) / Fact=측정값·외래키다수(매출·수량) Fact 테이블에 외래키가 많음
셀프서비스 BI 비즈니스 사용자가 직접 분석 데이터 신뢰도·거버넌스 문제가 단점
⑤ 분석 기법·모델 평가
개념시험용 한 줄 구분헷갈리는 포인트
과적합 vs 과소적합 과적합=학습데이터에만 맞고 일반화 안됨 / 과소적합=모델 너무 단순 과적합 해결=복잡도 낮추기·정규화
k-fold vs LOO k-fold=데이터를 k개로 나눠 반복 검증 / LOO=1개만 남겨 검증 LOO는 샘플 수만큼 반복해 연산 비용 큼
회귀 vs 로지스틱회귀 일반 회귀=수치 예측 / 로지스틱회귀=범주형 목표변수 예측 0/1 분류는 로지스틱회귀
