1. 데이터의 이해

1) 데이터의 개념

데이터(Data)

현실 세계에서 단순히 관찰하거나 측정하여 수집한 사실이나 값. 의미가 부여되지 않은 객관적 사실이며 가공하기 전 순수한 수치나 기호 자체.

  • 예 : 회원의 가입내역, 대리점의 매출내역, 회원의 시스템 로그인 시간 등

정보(Information)

의사결정에 유용하게 활용할 수 있도록 데이터를 처리한 결과물. 다양한 정보를 구조화해 유의미한 정보로 분류하며, 데이터 간 상관/연관관계 속에서 의미를 부여. 유용성은 상황에 따라 다름.

  • 예 : 회원 연령별 분포도, 대리점별 평균매출액, 회원들이 가장 많이 로그인한 시간대 등

지식(Knowledge)

정보를 바탕으로 의사결정에 활용하는 것. 개인의 경험에 결합해 고유의 지식으로 내재화하며, 각자 자기 관점에서 근거 데이터를 업무에 활용.

통찰(Insight)

지식의 축적과 아이디어가 결합된 창의적인 산물. 근본 원리에 대한 깊은 이해를 바탕으로 도출되는 창의적인 아이디어.

편의점을 예로 들면 — 하루 동안 팔린 상품 목록이 데이터, 이를 시간대·품목별로 집계한 것이 정보, "퇴근 시간대에 맥주와 안주가 함께 팔린다"는 분석이 지식, "저녁 6~8시에 맥주+안주 번들 할인을 운영하자"는 결론이 통찰이다.

2) 빅데이터의 개념

① 빅데이터의 3대 요소 : 3V

요소영문내용
규모Volume데이터의 양. 빅데이터를 사용하면 저밀도 비정형 데이터를 대량으로 처리해야 함. SNS 데이터 피드, 클릭 스트림, 센서 데이터 등이 해당. 일부 조직의 경우 수십 테라바이트 또는 수백 페타바이트에 달함
속도Velocity데이터의 수신 및 처리 속도. 메모리로 직접 스트리밍할 때 가장 빠름. 일부 스마트 제품은 실시간 또는 거의 실시간으로 작동하므로 실시간 평가 및 조치 필요
다양성Variety사용 가능한 데이터 유형의 다양성. 기존 정형 데이터 외에 텍스트·오디오·비디오 같은 비정형 및 반정형 데이터가 등장. 비정형·반정형 데이터는 의미 도출을 위해 추가 전처리 필요

② 빅데이터의 역사

  • 1960~70년대 : 최초의 데이터 센터 등장, 관계형 데이터베이스 개발 등 데이터 세상의 시작
  • 2005년 무렵 : 페이스북(Facebook)·유튜브(YouTube) 등 온라인 서비스를 통해 사용자 생성 데이터 인식 확산. 하둡(Hadoop) — 빅데이터 세트를 저장하고 분석하기 위해 특별히 개발된 오픈소스 프레임워크 — 이 개발되고, NoSQL(비관계형 데이터베이스관리시스템(DBMS))이 인기를 얻음
  • 이후 : 하둡(Hadoop)·스파크(Spark) 같은 오픈소스 프레임워크의 개발로 빅데이터를 손쉽고 저렴하게 저장·활용할 수 있게 되면서 빅데이터 시장 성장
  • 사물인터넷(IoT, Internet of Things) 출현으로 더 많은 객체와 장치가 인터넷에 연결되어 데이터 수집이 확대되고, 머신러닝의 등장으로 더 많은 데이터가 생성됨
  • 클라우드 컴퓨팅 : 빅데이터 가능성을 더욱 확장. 개발자가 임시 클러스터를 손쉽게 가동하여 데이터 하위 집합을 테스트할 수 있도록 탄력적인 확장성 제공
  • 그래프 데이터베이스 : 분석 속도를 높이고 포괄적인 방식으로 대량의 데이터를 표시할 수 있어 점점 더 중요해지고 있음
  • 빅데이터의 역사는 오래되었으나 빅데이터의 활용은 이제 시작단계로 볼 수 있음

③ 빅데이터의 사용 사례

사례내용
제품 개발빅데이터를 사용하여 고객 수요를 예측한 후 테스트 시장·초기 매장 출시 데이터 및 분석자료를 토대로 신규 제품을 계획·생산·출시
예측적 유지보수장비 생산연도·제조사·모델 같은 정형 데이터와 로그 항목·센서 데이터·오류 메시지·엔진 온도 등 비정형 데이터를 통해 장비 고장을 예측. 문제 발생 전 잠재적 문제 징후를 분석하여 비용 효율적인 유지보수 가능
운영 효율성생산·고객 피드백·반품·기타 요인을 분석·평가하여 운영 중단을 줄이고 향후 수요를 예측. 현재 시장 수요에 따라 운영 의사결정 개선
머신러닝빅데이터를 사용해 머신러닝 모델을 훈련하여 여러 분야에 활용

④ 빅데이터의 작동 원리

단계내용
통합서로 다른 종류의 소스와 어플리케이션으로부터 데이터를 수집하여 종합. ETL(Extract, Transform, Load, 추출·변환·로드) 같은 기존 데이터 통합 메커니즘은 일반적으로 적합하지 않으며, 테라바이트·페타바이트 규모 분석을 위한 새로운 전략과 기술 필요
관리스토리지(Storage)를 통해 데이터를 원하는 형식으로 저장하고 처리 요구사항에 따라 적용. 일반적으로 현재 데이터가 상주하는 위치에 따라 스토리지 선택
분석다양한 데이터 세트의 시각적 분석을 통해 명확성 확보 및 새로운 발견 탐색. 발견한 내용을 다른 사람들과 공유 가능. 머신러닝 및 인공지능으로 데이터 모델을 구축하고 업무에 활용

3) 데이터의 종류

① 형태에 따른 데이터 분류

유형내용예시
정형 데이터구조화된 데이터. 미리 정해진 구조에 따라 저장된 데이터엑셀 스프레드시트(행·열로 구성), 관계형 데이터베이스의 테이블 등
반정형 데이터구조에 따라 저장된 데이터지만 데이터 내용 안에 설명(구조 정보)이 함께 존재함. 구조를 파악하는 파싱(parsing) 과정이 필요. 보통 파일 형태로 저장웹 데이터 교환용 HTML·XML·JSON 문서, 웹 로그, 센서 데이터 등
비정형 데이터정해진 구조 없이 저장된 데이터. SNS 이용률 증가로 실시간으로 많은 양이 생산됨SNS의 텍스트·이미지·영상, PDF 문서 등 멀티미디어 데이터
정형·반정형·비정형의 차이 : 정형 데이터는 엑셀처럼 칸이 정해진 형태, 반정형 데이터는 JSON·XML처럼 구조 정보가 데이터 안에 같이 들어있는 형태, 비정형 데이터는 SNS 게시글·사진처럼 정해진 틀이 없는 형태다.

② 특성에 따른 데이터 분류

구분 세부 유형 특징 예시
범주형 데이터
(종류를 나타냄 / 크기 비교·연산 불가)		 명목형 데이터(Nominal Data) 순서(서열)가 없는 값 성별, 혈액형, 학과명, 거주지역, 음식메뉴, MBTI 검사 결과 등
순서형 데이터(Ordinal Data) 순서(서열)가 있는 값 학년, 학점, 회원등급 등
수치형 데이터
(크기 비교·연산 가능)		 이산형 데이터(Discrete Data) 개수를 셀 수 있는 띄엄띄엄 단절된 숫자 값 고객 수, 판매량, 합격자 수 등
연속형 데이터(Continuous Data) 측정을 통해 얻어지는 연속적으로 이어진 숫자 값 키, 몸무게, 온도, 점수 등

범주형 데이터 : 범주로 구분할 수 있는 값, 즉 종류를 나타내는 값을 가진 데이터. 크기 비교와 산술적인 연산이 가능하지 않아 질적 데이터라고도 함.

  • 명목형 데이터(Nominal Data) : 순서(서열)가 없는 값을 가지는 데이터. 성별·혈액형·학과명·거주지역·음식메뉴·MBTI 검사 결과 등
  • 순서형 데이터(Ordinal Data) : 순서(서열)가 있는 값을 가지는 데이터. 학년·학점·회원등급 등

수치형 데이터 : 크기 비교와 산술적인 연산이 가능한 숫자 값을 가진 데이터. 양적 데이터라고도 함.

  • 이산형 데이터(Discrete Data) : 개수를 셀 수 있는 띄엄띄엄 단절된 숫자 값. 고객 수·판매량·합격자 수 등
  • 연속형 데이터(Continuous Data) : 측정을 통해 얻어지는 연속적으로 이어진 숫자 값. 키·몸무게·온도·점수 등
이산형 vs 연속형 : 이산형은 "몇 명"처럼 딱 떨어지는 숫자, 연속형은 "키 172.3cm"처럼 소수점 이하까지 이어지는 숫자다.

2. 데이터의 해석

1) 데이터 해석 관점

① 데이터 해석 관점

  • 데이터 해석 : 데이터가 가진 의미를 파악하는 것
  • 데이터 해석 관점 : 데이터를 바라보는 다양한 관점. 어떠한 관점에서 바라보는지에 따라 의사결정 결과가 달라질 수 있음
예 : A화장품브랜드의 고객이 20대 여성 60%, 30대 여성 30%, 그 외 집단 10%로 구성되고, 매출액 비중은 20대 여성 50%, 30대 여성 40%, 그 외 집단 10%로 구성된다고 할 때 — ① 고객 중 높은 비중을 차지하는 20대 여성의 1인당 구매금액을 높이는 방향과, ② 1인당 평균 구매금액이 더 큰 30대 여성을 고객으로 확보하는 방향 등 다양한 마케팅 전략이 도출 가능하다.

② 데이터 해석 오류

데이터 해석 관점에 정답은 없으나, 데이터의 정확한 해석을 방해하는 오류에 대한 대처가 필요하다.

오류 유형내용예시
거짓 인과관계(False cause)우연히 나타난 현상이나 상관관계만 나타난 현상을 인과관계로 오인하는 것아이스크림 판매량과 익사 사고가 함께 늘어난다고 해서 아이스크림이 익사를 유발한다고 보는 것 (실제 공통 원인은 여름철 기온)
생존 편향(Survivorship bias)선택 과정을 통과한 개체의 데이터만 남아 통과하지 못한 개체의 데이터를 간과하는 논리적 오류서비스에 만족하지 않아 탈퇴한 가입자를 고려하지 않은 서비스 가입자 만족도
심슨의 역설(Simpson's paradox)세부 집단별로는 추세나 경향성이 나타나지만 전체적으로는 추세가 사라지거나 반대의 경향성이 나타나는 현상A 치료법이 남성 집단에서도, 여성 집단에서도 각각 더 좋은 효과를 보였는데 남녀 데이터를 합쳐 전체로 보면 오히려 B 치료법이 더 좋아 보이는 경우 (집단 구성 비율이 다를 때 발생)
체리피킹(Cherry picking)불리한 데이터나 사례는 숨기고 유리한 데이터만 활용하여 주장을 뒷받침하는 것신제품 만족도 조사에서 긍정 후기 3개만 보여주고 불만 후기 50개는 제외하는 것

2) 데이터 기초 통계

① 통계

특정 집단에 대하여 조사나 실험을 통해 얻은 수치를 활용하여 특정 집단을 구성하는 각각의 정보를 하나의 요약된 값으로 표현한 것.

② 주요 통계 용어

분석 단위 관련 용어

용어내용
모집단연구와 조사 또는 분석이 이루어지는 집단 관심 대상 전체
표본(Sample)일반적으로 모집단 전부를 수집하여 분석할 수 없으므로 일부분을 추출하여 분석하는 대상
기술통계수집한 데이터를 정리·요약·해석 등을 통해 데이터의 특성과 속성을 파악하는 방법
추론통계표본으로부터 통계량 등의 값을 계산하여 모집단의 특성과 속성을 파악하는 방법
확률어떤 사건이 실제로 일어날 것인지 혹은 일어났는지에 대한 지식 혹은 믿음을 표현하는 방법이며, 같은 원인에서 특정한 결과가 나타나는 비율
조건부 확률주어진 사건이 일어났다는 가정하에 다른 한 사건이 일어날 확률. 사건 B가 일어났다는 가정하에 사건 A가 일어날 조건부 확률은 Pr(A|B)로 표기
도수분포표데이터가 속하는 항목 또는 특정 범위의 빈도를 나타낸 표
히스토그램데이터가 속하는 항목 또는 특정 범위의 빈도를 나타낸 그래프
가설검정통계적 추측의 하나로서, 가설(모집단 실제의 값이 얼마가 된다는 주장)에 대해 표본의 정보를 사용해서 합당성 여부를 판정하는 과정

중심경향값 (데이터의 중심을 나타내는 값)

용어내용
평균(Mean)전체 데이터의 총합을 전체 데이터의 수로 나눈 값
중앙값(Median)전체 데이터를 나열했을 때 가운데에 있는 값. 홀수개이면 가운데 값, 짝수개이면 가운데 두 값의 평균
최빈값(Mode)전체 데이터 중 가장 높은 빈도를 보이는 값
10명의 월급이 200만원대인데 1명이 10억을 받는다면 — 평균은 그 1명 때문에 크게 올라가고, 중앙값은 가운데 있는 사람의 월급이라 200만원대를 유지하며, 최빈값은 가장 많이 나타나는 200만원대가 된다. 극단값이 있을 때는 평균보다 중앙값이 더 대표성이 있다.

산포도 및 관계 (데이터가 얼마나 퍼져 있는지, 변수 간 관계)

용어내용
분산(Variance)확률변수가 기댓값으로부터 얼마나 떨어진 곳에 분포하는지를 가늠하는 숫자. 기댓값은 확률변수의 위치, 분산은 얼마나 넓게 퍼져 있는지를 나타냄. 분산보다는 표준편차를 더 자주 사용
표준편차(Standard Deviation)분산의 제곱근을 취한 값
공분산(Covariance)두 변수가 각자의 평균으로부터 멀어지는 값
상관계수(Correlation Coefficient)두 변수 사이의 통계적 관계를 표현하기 위해 특정한 상관관계의 정도를 수치로 나타낸 것
광고비가 늘어날수록 매출도 함께 늘어나는 경향이 있다면 두 변수는 양의 상관관계, 기온이 올라갈수록 난방비가 줄어드는 경향이 있다면 음의 상관관계다. 상관계수는 이 관계의 강도를 -1에서 1 사이의 숫자로 나타낸다.

3) 확률과 확률분포

① 확률분포

확률변수가 특정한 값을 가질 확률을 나타내는 함수. 확률변수의 종류에 따라 이산확률분포와 연속확률분포로 나뉜다.

② 이산확률분포

이산확률변수(가질 수 있는 값의 개수를 셀 수 있는 확률변수)의 확률분포.

예 : 주사위를 던져서 나오는 눈의 수(1~6)는 셀 수 있으므로 이산확률변수에 해당한다.
분포내용
베르누이분포결과가 두 가지 중 하나로만 나오는 시행(베르누이시행)이 나타내는 확률분포
이항분포N번의 독립적인 베르누이시행 중 성공횟수의 확률분포. 베르누이분포는 시행횟수가 1인 경우
기하분포성공확률이 p인 베르누이시행에서 처음 성공이 일어날 때까지 반복한 시행횟수의 확률분포
음이항분포성공확률이 p인 베르누이시행을 r번 성공할 때까지 반복시행한 횟수의 확률분포. 기하분포는 성공횟수 r=1인 음이항분포
초기하분포N개 중 비복원추출로 n번 추출했을 때 원하는 것이 k개 포함될 확률의 분포
푸아송(Poisson)분포단위 시간 내에 어떤 사건이 발생하는 횟수를 나타내는 분포
동전을 한 번 던져 앞면/뒷면 중 하나가 나오는 것은 베르누이분포, 동전을 10번 던져 앞면이 몇 번 나오는지를 보는 것은 이항분포에 가깝다. 하루 동안 콜센터에 걸려오는 전화 건수처럼 일정 시간 동안 사건이 몇 번 발생하는지를 볼 때는 푸아송분포를 활용할 수 있다.

③ 연속확률분포

연속확률변수(가질 수 있는 값의 개수를 셀 수 없는 확률변수)의 확률분포.

예 : 중학교 1학년 학생의 평균 키는 실수 값을 가지며 셀 수 없으므로 연속확률변수에 해당한다.
분포내용
정규분포중심극한정리에 따라 동일한 분포를 가지는 많은 확률변수의 평균 분포를 근사할 수 있는 분포. 중심극한정리 : 어떠한 확률분포라도 정해진 횟수 n만큼 독립적으로 추출하는 작업을 반복했을 때 추출된 값의 평균은 n이 커짐에 따라 정규분포에 근접함
감마분포a번째 사건이 일어날 때까지 걸리는 시간에 대한 연속확률분포
지수분포사건이 서로 독립적일 때 사건과 사건 간의 경과시간에 대한 확률분포
카이제곱분포k개의 서로 독립적인 표준정규확률변수의 제곱을 합한 값에서 얻어지는 분포
베타분포두 매개변수 α와 β에 따라 [0, 1] 구간에서 정의되는 연속확률분포
균등분포(균일분포)특정구간 내의 값들이 나타날 가능성이 균등한 분포
많은 사람의 키나 시험 점수처럼 평균 주변에 값이 몰리고 양쪽으로 갈수록 적어지는 형태는 정규분포로 설명할 수 있다. 정규분포가 중요한 이유는 중심극한정리에 의해 표본 수가 충분히 크면 어떤 분포든 평균의 분포가 정규분포에 가까워지기 때문이다.

4) 데이터 마이닝

① 데이터마이닝 개념

  • 복잡하고 방대한 데이터 세트에서 의미 있는 정보를 추출하고, 이를 통해 실질적인 가치를 창출하는 일련의 과정
  • 데이터베이스, 데이터 웨어하우스 또는 다양한 데이터 저장소에서 데이터를 검색하고, 통계 분석·머신러닝·패턴 인식·인공지능 등의 기술을 활용

② 데이터마이닝의 활용 분야

분야활용 예
비즈니스 및 마케팅고객 세분화, 시장 분석, 추천 시스템
금융신용 평가, 사기 탐지
의료질병 진단, 약물 연구
인터넷 및 소셜 미디어소셜 네트워크 분석, 웹 마이닝
공공 안전 및 법 집행범죄 분석, 재난 대응
과학 및 공학환경 분석, 공학 설계 최적화

③ 데이터마이닝의 단계

단계내용
① 데이터 수집다양한 소스에서 정형·비정형 형태로 데이터 수집
② 데이터 정제오류·누락값·중복 데이터 제거 및 품질 향상
③ 데이터 변환분석하기 쉽도록 형식 변경. 스케일링·정규화·차원 축소 등
④ 데이터 저장가공된 데이터를 데이터베이스 또는 데이터 웨어하우스에 저장
⑤ 데이터 탐색데이터의 특성을 이해하고 품질 평가. 기초 통계 분석·시각화 등 활용
⑥ 데이터 분석분류·군집화·예측 등 목적에 부합하는 알고리즘 선택 및 모델 구축
⑦ 결과 해석분석 결과를 맥락적으로 해석하고 비즈니스 문제나 의사결정에 적용
⑧ 모델 평가교차 검증, 성능 지표(정확도·정밀도·재현율 등)로 모델 성능 평가
⑨ 의사결정결과를 기반으로 의사결정을 내리거나 비즈니스 프로세스 최적화에 활용

④ 데이터마이닝의 분석 기술

연관분석

  • 데이터 집합에서 항목 간의 연관성을 찾는 기법. 항목 간의 연관성과 지지도·신뢰도·향상도 등을 측정
  • 함께 구매하는 상품의 조합이나 서비스 패턴을 발견하고자 할 때 많이 사용하여 장바구니 분석이라고도 함
  • Apriori 알고리즘 : 연관 규칙 학습에 자주 사용됨. 아이템의 지지도(특정 아이템 세트가 전체 트랜잭션에서 차지하는 비율)와 신뢰도(한 아이템이 주어졌을 때 다른 아이템이 함께 나타날 조건부 확률)를 계산하여 유의미한 규칙을 선별
예 : "감자칩을 구입하는 고객의 30%는 맥주도 함께 구입한다", "수요일 저녁에 우유를 구입하는 고객의 40%는 기저귀도 함께 구입한다"와 같은 연관성을 분석함

군집분석

  • 데이터를 유사한 집단으로 그룹화하여 각 집단의 성격을 파악하는 기법
  • 데이터 포인트 간의 유사도를 기반으로 군집을 형성하고 각 군집의 특성을 파악
  • 시장 세분화, 소셜 네트워크 분석 등에 사용됨
  • K-평균(K-means) 군집화와 계층적 군집화가 대표적인 알고리즘
    • K-평균 군집화 : 그룹화할 군집의 수(K)를 사용자가 지정. 각 군집의 초기 중심점을 무작위로 선택하고, 데이터 포인트들을 가장 가까운 중심점 기준으로 군집에 할당. 할당된 데이터 포인트들의 평균 위치로 각 군집의 중심점을 재조정하며, 군집의 할당이 더 이상 변하지 않을 때까지 반복

분류분석

  • 데이터 포인트를 미리 정의된 클래스 또는 범주로 할당하는 작업
  • 지도 학습 알고리즘을 사용하여 모델을 훈련하고, 새로운 데이터를 정의된 클래스로 분류
  • 의사결정나무(Decision Tree)·랜덤 포레스트·서포트 벡터 머신 등이 분류 알고리즘으로 사용됨
  • 의사결정나무(Decision Tree) : 의사결정 규칙을 나무 구조로 표현. 노드와 가지로 구성되며, 각 노드는 변수를 의미하고 마지막 노드는 결과값을 의미. 나무에서 내려올수록 더 세분됨
고객이 이탈할지 여부를 분류할 때 — "나이가 30세 이상인가?" → "구매 횟수가 3회 이상인가?" → "최근 6개월 내 구매했는가?"처럼 기준을 나무 가지 형태로 내려가며 분류한다.

회귀 예측

  • 연속형 변수의 값을 예측하는 기법
  • 예측 변수와 목표 변수의 관계를 모델링하고, 이를 통해 목표 변수의 값을 예측
  • 주택 가격·주식 가격 등을 예측할 때 사용
  • 선형 회귀, 다항 회귀, 릿지 회귀, 라쏘 회귀 등이 대표적 알고리즘
광고비(예측 변수)를 늘릴수록 매출(목표 변수)이 얼마나 증가하는지 관계를 수식으로 표현하는 것이 회귀 예측이다.

이상 탐지

  • 정상 데이터와 다른 비정상적인 데이터 포인트를 식별하는 기법
  • 통계적 이상 탐지, 머신러닝 기반 이상 탐지, 클러스터링 기반 이상 탐지 등 다양한 방법 활용
  • 사기 탐지, 네트워크 보안, 결함 감지 등에 활용

텍스트 마이닝

  • 텍스트 데이터에서 정보를 추출하고 텍스트의 패턴 및 특성을 분석하는 기술
  • 자연어 처리 기술과 기계 학습을 결합하여 문서 분류·감성 분석·주제 모델링 등에 사용

차원 축소

  • 고차원 데이터의 특성을 줄여 시각화하거나 분석하기 쉽게 만드는 기법
  • PCA(주성분 분석, Principal Component Analysis)·t-SNE(t-distributed Stochastic Neighbor Embedding) 등이 대표적

신경망 및 딥러닝

  • 복잡한 패턴 및 특성을 추출하는 데 강력한 도구
  • 이미지 분류·음성 인식·자연어 처리 등 다양한 분야에 활용
